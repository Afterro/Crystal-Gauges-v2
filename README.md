# Crystal Gauges V2

A simple Assetto Corsa gauge pack inspired by No Hesi tacho gauge
Rewritten for better scalability and new functions such as startup animations, glow, better gradients and headlight state dependant brightness

> No settings options are currently available ingame

# Future plans

- Tachometer **(Done)**
- Minimap **(Done)**
- Media player ***(WIP)***
- Instruments - Headlights, indicators, wipers etc. ***(Currently partially in tacho)***
- Boost gauge - Pretty much reskinned tacho
- Fuel gauge - Same as boost
- Inputs - Pedals, wheel, gear changes, FFB,  *also with a graph of past inputs*
- Lap times and delta bar
- Tyre telemetry
- G-Force meter
- Settings *duh...*
- and probably something else...

All apps will include headlight state and time dependant transparency, so you don't drive with your lights off.
I'm also trying to implement startup animations, but that may be too much complexity to be worth it for more advanced animations. *Or maybe I just need to code smarter*

Will I do all that? Maybe

# Installation

## Content Manager drag and drop
1. Download the latest version from [releases](https://github.com/Afterro/Crystal-Gauges-v2/releases)
2. Drag and drop the zip to Content Manager
3. Install the app

## Manual
Download the source code and extract the contents of the zip file to `assettocorsa\apps\lua\`
